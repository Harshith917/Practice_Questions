Q4 )

Polymorphism is the ability of an object to behave differently at different instance of time.

a: Compile-time Polymorphism: 
	
	-> It is the process of binding method declaration with its method implementation 	   which is done by compiler during the compilation.
	-> It is also called as static/early binding.
	-> Eg: Achieved using Methodoverloading.
	-> Realtime Example : Phonepe send button acts differently based on the content we 	   use like if we enter amount it acts like transaction button and if we enter any 	   string content(message) it acts like normal sending message button.

   Run-time Polymorphism: 
	-> It is the process of binding method declaration with its method implementation 	   during execution which is done by JVM.
	-> It is also called as Dynamic/Late binding.
	-> Eg: Achieved using Methodoverriding.


b: Runtime polymorphism is achieved using Methodoverriding.


c: Runtime polymorphism is important because it allows changing method behavior/implementation during runtime so that we need not to change previous code when we add new code and also enables loose coupling.
